# Satellite Collision Risk Prediction using KNN and Mahalanobis Distance

## Overview

This project predicts the risk of satellite collisions using Machine Learning.

The model uses:

- K-Nearest Neighbors (KNN)
- Mahalanobis Distance
- SMOTE for class balancing
- StandardScaler for feature normalization

## Dataset Features

- miss_distance
- relative_speed
- c_sigma_r
- c_sigma_t
- c_sigma_n
- time_to_tca

Target:

- collision_risk
    - 0 = Low Risk
    - 1 = High Risk
